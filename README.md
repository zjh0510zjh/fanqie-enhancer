## ✨ 核心功能特性

1. **作者主页下架神作穿透显形**：
   * 打开任意番茄作者个人主页（），全自动扫描作者隐藏头衔与历史名录；
   * 在列表底部以优雅橙色卡片展示已下架作品，支持**一键复制 19 位真实书号**！

2. **官方全网极速搜索**：
   * 支持搜书名、搜作者名、以及输入 19 位书号秒级直达；
   * 纯官方公开网关直连，零本地依赖，回车即搜，毫秒响应！

3. **双书名并列展示**：
   * 在榜单和详情页，直接并列展示【当前主书名 + 曾用原名】。

4. **榜单多维运营指标透视与重排序**：
   * 14天阅读UV、30天总阅读、历史加书架、字数等 8 大核心指标即时重排。
